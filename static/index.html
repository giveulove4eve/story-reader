📱 在安卓手机 / 其他设备上使用

只要手机和电脑连接在同一个 Wi-Fi 网络下，手机浏览器打开下方网址即可直接使用：

http://192.168.x.x:8000

💡 安卓手机如何变成独立 App：

  1. 在手机 Chrome 或自带浏览器 中打开上方网址；
  2. 点击浏览器右上角的 ⋮（菜单）；
  3. 选择 “添加到主屏幕” 或 “安装应用”；
  4. 桌面就会出现 App 图标，全屏无边框，随时复制文字粘贴听读！
